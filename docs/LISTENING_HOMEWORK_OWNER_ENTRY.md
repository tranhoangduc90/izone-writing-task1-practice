# Listening Homework owner entry

Native Listening Homework reuses the verified Homework registry guard without moving data into another product. `app.js` passes the configured `ownerEntry` to the web router and applies the same document header to student audio authorization. `/teacher/entry?documentId=...` resolves a registered binding and checks native teacher class access; historical work remains available after learner withdrawal, as with the existing teacher workspace.

Per-lesson private `homework.ownerEntry` contains the class ID/code pairs already allowed for that lesson. With `verifyCourseFromOwnerSource: true`, a fresh owner source is mandatory and its Classroom course/Google user must match the registered target on student requests. Existing pinned-course Reading policies retain their contract. A document never grants credentials or class access; the generic ERP route remains independent of Classroom mapping. No Google sign-in is required for students.

Deployment uses `Dockerfile.owner-entry` on an inspected existing Listening image. Verify the named local base tag resolves to that exact image before building; a bare `sha256:<image-id>` is not a valid BuildKit repository reference. Overlay the native app plus owner guard, router, Homework runtime factory, Homework planner and CTA registrar together. Updating only app/guard leaves CTA URLs generic on older images. Preserve model/rubric/lesson/audio config, network aliases, limited database role and teacher SSO source `listeninghomework`; never restore the work database when rolling code back.

The frontend uses `/entry` before student session restoration/lesson/draft/history reads, automatically remembers valid ERP selections, and locks personal links to their verified owner/class. Native teacher intent remains separate. Keep `assignmentCode`, Doc context and legacy aliases on change-person/logout. A tab keeps its own saved work when another tab changes common memory. Registering a modern Homework target produces a contextual CTA; this does not migrate historical Docs grading pipelines.

Validation: `backend/test/listening-homework-owner-entry.test.js` covers login, protected reads/writes/audio, scope/version/mapping/source failures, teacher history/permission, and current-course policy. Existing Listening and shared Homework tests remain applicable. Pages has `tests/listening-homework-owner-entry-browser.mjs`. The release's private evidence separately records RED on the previous app, current browser/API tests, native PostgreSQL/CTA-factory readback, and worker-disabled startup against the real read-only authority. Fixture Google/Docs results are not real Google sign-in or Classroom proof.
