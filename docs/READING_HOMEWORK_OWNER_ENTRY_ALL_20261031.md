# Reading Homework owner entry rollout

The Lesson 12 owner-entry pilot is extended to all six existing Reading Homework products. `ownerEntry.classes` contains authority-verified ERP class/code and Classroom course pairs. The original single-class pilot policy remains compatible. Assignment code and content version stay unchanged; the registry selects exactly one matching document and must agree with its owner, class, assignment, Classroom course and submission metadata. Entry resolution and protected requests recheck current membership and the current Classroom mapping.

Root Materials and the Headings adapter now pass the same owner guard to the native router. Root Materials accepts configured classes from the current authority instead of its old IC2304-only startup restriction, and keeps the original PostgreSQL/database/grader checks. Existing teacher authorization, SSO, read-only routes and result links remain native. No migration or learner answer/attempt write is part of the rollout.

Private configuration extends each lesson's existing class set with current `on_going` K67 ERP classes; it does not remove existing grants. Root Materials uses the existing wider owner source. Classes with no approved mapping keep no fabricated students or personal bindings. Only verified existing personal Homework copies are rewritten, using the native idempotent registrar and hyperlink-only planner. Historical Homework using other products is preserved.

Validation: 51 SQL/HTTP tests passed against the exact live source overlay, including six assignments across two classes, changed mapping, revoked access and retained business data. Browser tests cover generic/personal entry on all six lessons, wrong shared memory and stale tab sessions, and teacher separation; existing teacher SSO regression checks passed. Canary resolved all 32 registered owner targets and rejected unknown documents on six routes. Production native checks cover wrong login, mismatching draft context, matching draft reads and session revocation; no learner answers were entered, submitted, reset or graded.

Pages PR398 is merged and published. Production uses the own Reading Homework service image `izone-reading-homework:owner-entry-all-20261031-v1`. Private deployment records include the previous container/config, database dump, canary, readbacks, Docs snapshots and rollback container under `/opt/izone-reading67-owner-entry-all-20261031`. Rollback restores code/config, not the database. No shared Progress Log/attendance runtime or n8n workflow was changed.

Limits: the learner identity is still name selection/shared ERP memory, not Google authentication. Generic legacy URLs have no personal owner context. No physical learner device was tested. Source inventory and private receipts distinguish existing registry copies from historical Homework and classes without a synchronized roster.
