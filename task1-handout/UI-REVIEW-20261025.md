# Snapshot cho giao diện Earnings thử

API đọc phiên/lượt chấm bổ sung `snapshot` từ chính check_attempt bất biến. Dòng thời gian không được dùng bản nháp hiện tại để thay đầu vào cũ. Projection lịch sử cũng đọc snapshot gốc khi có, hoặc trả null; không sửa kho lịch sử.

Thay đổi chỉ là projection đọc, không migration, đổi prompt, job, PIN, quyền hoặc điều kiện chấm. Đã triển khai riêng API thử `/task1-preview-api/` bằng image `task1-preview:earnings-ui-20261025.1`; worker/DB và runtime production giữ nguyên. Bản sao container API thử trước đó giữ tên `task1-preview-api-before-earnings-ui` để quay code, không restore dữ liệu.
