# Snapshot cho giao diện Earnings thử

**Cập nhật sau khi Đức chốt bản thử:** projection đã phát lên API Task 1 riêng production bằng image `.5-ui-snapshots`; [biên nhận và bảo toàn18 bảng](PRODUCTION-UI-20261025.md). Các câu “chưa phát production” bên dưới là mốc kiểm Earnings trước khi được giao làm tiếp.

API đọc phiên/lượt chấm bổ sung `snapshot` từ chính check_attempt bất biến. Dòng thời gian không được dùng bản nháp hiện tại để thay đầu vào cũ. Projection lịch sử cũng đọc snapshot gốc khi có, hoặc trả null; không sửa kho lịch sử.

Thay đổi chỉ là projection đọc, không migration, đổi prompt, job, PIN, quyền hoặc điều kiện chấm. Cả GET phiên và phản hồi saveDraft đều giữ snapshot. Đã triển khai riêng API thử `/task1-preview-api/` bằng image `task1-preview:earnings-ui-20261025.2`; worker/DB và runtime production giữ nguyên. Lần phát .2 đồng bộ thêm app/dashboard/legacy-router hiện hành để tuyến CSV có trên API thử. Bản sao container API thử trước .2 giữ tên `task1-preview-api-before-earnings-ui-r2` để quay code, không restore dữ liệu.

Kiểm: 23/23 ca backend, gồm bản đã gửi khác nháp mới, lịch sử chỉ đọc/quyền lớp/PIN/conflict/idempotency/queue/comment và CSV. Lệnh từ thư mục này: `node --expose-gc --test --test-concurrency=1 test/product.test.mjs test/history.test.mjs test/cutover.test.mjs test/ui-snapshot.test.mjs`.
